# جوليث

🧾 مشروع موقع كافيه VOUTE (فوت)

🎯 هدف المشروع

تصميم موقع بسيط (Landing Page) لكافيه VOUTE يعكس هوية القهوة المختصة بأسلوب كلاسيكي أنيق بلمسة تراثية سعودية، مع تجربة مريحة بصريًا وسهلة الاستخدام.

🪄 الفكرة العامة

الموقع عبارة عن صفحة واحدة (One Page Website) تركز على:

 إبراز هوية الكافيه

 عرض المنيو بشكل أنيق

 تسهيل الوصول لحسابات التواصل والموقع

🎨 التصميم (UI/UX)

🧩 الهوية البصرية

 الألوان الأساسية:

 بيج (Beige) – خلفيات مريحة

 ذهبي هادئ (Soft Gold) – للعناوين والعناصر المهمة

 ألوان مساعدة:

 بني قهوة داكن

 أبيض كريمي

✨ الستايل العام

 كلاسيكي فاخر (Classic Elegant)

 لمسات تراث سعودي (نقوش خفيفة / Patterns مستوحاة من السدو أو العمارة النجدية)

 تصميم مريح للعين (Minimal + Spacious)

🔤 الخطوط

 عربي أنيق (مثل: GE SS / أو خط مشابه فاخر)

 استخدام وزنين فقط (Regular + Bold)

🏗️ هيكل الصفحة (Layout)

1. 🟤 القسم الرئيسي (Hero Section)

 خلفية ناعمة (بيج أو صورة قهوة ضبابية خفيفة)

 في المنتصف:

"نقدم لك فنا في كل كوب"

 بخط كبير وأنيق

 تأثير دخول بسيط (Fade In)

2. 📋 قسم المنيو (Menu Section)

 عرض المنيو بشكل مرتب:

 تصنيفات (مثلاً):

 قهوة ساخنة

 قهوة باردة

 إضافات

 كل عنصر يحتوي:

 اسم المشروب

 السعر

 التصميم:

 بطاقات (Cards) بخلفية بيج فاتح وحدود ذهبية خفيفة

 Hover effect بسيط

3. 🔗 قسم الروابط (Social & Location)

عرض أيقونات بشكل أنيق:

 📸 إنستقرام

 🎵 تيك توك

 📍 الموقع على خرائط قوقل

استخدم الرابط التالي للموقع:
https://maps.app.goo.gl/LxvH6QnXXkyr3k1cA

طريقة العرض:

 أيقونات دائرية بلمسة ذهبية

 عند الضغط:

 تفتح في تبويب جديد

 إضافة Hover Animation (تكبير بسيط أو توهج ذهبي)

⚙️ المتطلبات التقنية

💻 التقنيات المقترحة

 HTML5

 CSS3 (أو Tailwind)

 JavaScript بسيط (للحركات)

 الموقع يكون:

 Responsive 100% (مهم للجوال)

 سريع وخفيف

🎞️ الحركات (Animations)

 Fade-in عند التمرير

 Smooth scrolling

 Hover effects ناعمة

 بدون مبالغة (Minimal Animations)

📱 تجربة المستخدم (UX)

 الموقع يفتح بسرعة

 سهل التصفح

 واضح وبسيط

 مناسب للجوال أولاً (Mobile First)

💡 تفاصيل إضافية مهمة

 عدم تعقيد التصميم

 التركيز على الفخامة والبساطة

 إضافة مساحات بيضاء كافية (Whitespace)

 استخدام صور قهوة عالية الجودة (إن توفرت)
